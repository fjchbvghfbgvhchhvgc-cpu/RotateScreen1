# RotateScreen

Windows 11 横竖屏切换工具(带悬浮按钮) / Floating-button screen rotation tool for Windows 11.

## 用法 / Usage

1. 双击 `RotateScreen.exe` → 屏幕右下角出现一个蓝色圆形悬浮按钮。
2. **左键单击** → 在 0°(横屏)与 90°(竖屏)之间切换。
3. **左键拖动** → 把按钮移到任意位置。
4. **右键** → 弹出菜单,可手动旋转或退出。

---

1. Double-click `RotateScreen.exe` → a blue circular floating button appears at the bottom-right of the screen.
2. **Left click** → toggle between 0° (landscape) and 90° (portrait).
3. **Left drag** → move the button anywhere.
4. **Right click** → context menu to rotate manually or exit.
