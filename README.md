# RotateScreen

Windows 11 横竖屏切换工具 / Toggle landscape/portrait orientation on Windows.

## 用法 / Usage

双击 `RotateScreen.exe` → 屏幕在 0° 与 90° 之间切换。
Double-click `RotateScreen.exe` to toggle between 0° and 90°.

## 编译 / Build

每次 push 自动通过 GitHub Actions 编译。
APK 在 Actions → Workflow run → Artifacts 下载。

Built automatically by GitHub Actions on every push.
Download EXE from Actions → workflow run → Artifacts.
